# QI — Quality Intelligence CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Python CLI (`qi`) that scaffolds a new AI-assisted QA project in seconds, generating a Claude-first constitution (CLAUDE.md), rules, skills, and scripts customized to the team's stack.

**Architecture:** Interactive CLI using Typer + Questionary collects project config, a Jinja2-based generator renders templates into the target directory, and a thin `Config` dataclass carries all choices between steps. Templates live under `qi/templates/` and are rendered conditionally based on the user's answers.

**Tech Stack:** Python 3.11+, Typer, Questionary, Jinja2, Rich — all installable via pip. No external services required.

---

## File Map

| File | Responsibility |
|---|---|
| `qi/cli.py` | Entry point — wires Typer command, calls prompts → generator |
| `qi/prompts.py` | All Questionary interactive questions → returns `Config` |
| `qi/config.py` | `Config` dataclass holding all user choices |
| `qi/generator.py` | Renders Jinja2 templates into target directory |
| `qi/templates/CLAUDE.md.j2` | Generic AI constitution |
| `qi/templates/README.md.j2` | Project README |
| `qi/templates/COVERAGE.md.j2` | Coverage tracker template |
| `qi/templates/rules/*.md.j2` | Generic `.claude/rules/` files |
| `qi/templates/skills/*.md.j2` | Generic `.claude/skills/` files (some conditional) |
| `qi/templates/scripts/qa_track.py.j2` | Generic activity tracker |
| `qi/templates/scripts/coverage_report.py.j2` | Coverage report script |
| `qi/templates/specs/README.md.j2` | Domain spec guide |
| `qi/templates/ci/*.yml.j2` | CI workflow templates (conditional) |
| `tests/test_generator.py` | Generator unit tests |
| `tests/test_prompts.py` | Config/prompt unit tests |
